# 管理思維座標

直接以瀏覽器開啟 `index.html` 即可使用，不需要安裝套件、建置或後端。部署時將本資料夾的 HTML、CSS、JavaScript 與原始 PNG 圖檔一起放到靜態主機。

## 問卷設計

依「企業管理思維四象限演化圖.png」將企業模式轉為個人管理傾向，28 題分為四頁，各頁七題。建議依最近三個月同一角色的實際行為作答。

- 信任與自主軸：奇數題，3、7、11、15、19、23、27 正向，其餘反向。
- 能力成長軸：偶數題，2、6、10、14、18、22、26 正向，其餘反向。
- 每題 1–5 分；反向換算為 6 減原分。各軸分數為 `(平均分 - 1) / 4 * 100`。
- 自主低／成長低：控制型；自主低／成長高：訓練型；自主高／成長低：菁英型；自主高／成長高：學習型。
- 以未取整數的 50 分為分界；任一軸等於 50 顯示混合型。任一軸落在 40–60 分（含）會提供相鄰模式提示。

題目、分界和混合提醒為自編規則，未經信效度驗證。結果適合自我反思與討論，不應用於招募、考核或推論企業整體文化。

## 功能與資料

響應式版面、必填檢查、返回修改、原圖檢視、四象限結果、文字檔下載、瀏覽器列印／PDF、重新測驗。無外部套件或網路資源，答案僅存在頁面記憶體，重新整理即清除；下載內容包含作答紀錄。

## 本機預覽

可直接開啟 HTML，或在資料夾執行 `python -m http.server 8080 --bind 127.0.0.1`，瀏覽 `http://127.0.0.1:8080`。

## 28 題版本與配色

兩軸各 14 題，各 7 題正向及反向。新增第 25–28 題補充責任意願、能力改善、主動性、能力上限；預估填答 6–8 分鐘。總題數、每頁題數與計分分母由題庫及常數決定。

以《為這美好的世界獻上祝福！》官方視覺作配色靈感，採天空藍、紅、黃、綠與白色卡片。原圖維持不變。參考：https://konosuba.com/3rd/ 。
